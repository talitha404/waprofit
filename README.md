# Waprofit

Waprofit adalah SaaS berbasis web yang membantu pengguna membuat dan mengedit dokumen secara cepat menggunakan template siap pakai dan fitur kalkulator profit riil setelah pajak.

## Teknologi yang Digunakan
* Backend: Laravel 11
* Frontend: Blade + Tailwind CSS
* Interactivity: Alpine.js
* Database: MySQL
* Authentication: Laravel Breeze
